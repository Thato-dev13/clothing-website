KLEAN

KLEAN is a clothing website I built to put everything I’ve been learning about web development into one big project.

It took me around 2 months to build. After spending time learning and practicing different parts of web development, I decided I wanted to take everything I had learned and put it together into one larger project instead of just making small practice projects.

Why I Built KLEAN

I wanted to challenge myself and see what I could create with the skills I had developed so far.

KLEAN gave me the chance to work on a real website from start to finish, from the design and layout to making the pages interactive and responsive.

There were definitely times when I got stuck or had to redo things, but figuring those problems out was a big part of the learning process.

Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub

What I Learned

Building KLEAN helped me understand how the different things I’ve been learning actually come together when building a bigger project.

Some of the things I improved on include:

* Writing HTML and structuring webpages
* Styling websites with CSS
* Making websites responsive
* Using JavaScript to add functionality
* Creating a better user interface
* Improving my understanding of UI/UX
* Debugging and solving problems
* Using Git for version control
* Using GitHub to manage and store my project

Future Improvements

I still want to continue improving KLEAN as I learn more.

Some things I would like to work on in the future are:

* Adding more features
* Improving the UI/UX
* Making the website more responsive
* Adding backend functionality
* Improving the shopping experience
* Making the website more like a real-world clothing store

👨🏽‍💻 Why This Project Matters To Me

KLEAN is one of the biggest projects I’ve worked on so far.

I started it after deciding to stop only learning and actually use what I had learned to build something of my own. The project isn’t perfect, and there’s still a lot I can improve, but that’s what makes it valuable to me.

It shows where my skills were after putting around 2 months of learning and practice into web development, and I plan to keep improving it as I continue learning.

This is only the beginning.
